System architecture — one primary, many read replicas

The application writes to the primary only. The primary's binlog replicates out to read replicas; reads fan back from the replica pool.

One primary owns every write; replicas are read-only copies. Replication is asynchronous — a replica can be milliseconds-to-seconds behind, so never read-your-own-write from a replica. The write path is one node; the read path scales horizontally.
