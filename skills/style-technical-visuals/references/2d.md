## Preserve the visual language

Preserve existing product tokens. For an unbranded artifact, copy the selected
example's shared `:root` token block; keep raw colors there and use semantic
names throughout drawing and controls.

| Role | Standalone fallback |
| --- | --- |
| Canvas / panel | `#111111` / `#1c1c1c` |
| Text / muted / dim | `#fafafa` / 60% / 40% opacity |
| Border / node border / track | White at 14% / 22% / 10% opacity |
| Focus or selected teaching point | `--accent: #f35815` |
| Success / warning / failure / information | `#27b648` / `#d19f03` / `#ff455d` / `#1e9de7` |

Use the system monospace stack for labels, controls, and metrics; use tabular
numbers for changing values. Keep longer prose readable. Use thin borders,
restrained radii, direct labels, and space around the main explanation.
Map each state or series color to one meaning across nodes, edges, and counters;
combine color with text, shape, position, or line style. Apply orange sparingly
for focus rather than decoration. If light mode is required, adapt contrast and
surface separation deliberately instead of mechanically inverting colors.

## Build geometry from meaning

1. Assign semantic shapes: cylinders for databases, panels for services,
   slotted buffers for queues, and record blocks or rows for data. State any
   diagram-specific meaning. Reuse attributed technology marks only when they
   identify the actual technology; keep visible names beside decorative marks.
2. Place nodes, labels, wires, arrowheads, and packets in one SVG coordinate
   system. Store node bounds once and derive ports from them. For bounds
   `(x, y, w, h)`, face centers are `(x, y+h/2)`, `(x+w, y+h/2)`,
   `(x+w/2, y)`, and `(x+w/2, y+h)`. Bounds must describe outline extrema.
3. Use facing ports and the fewest bends that clear unrelated nodes and labels.
   Leave and enter perpendicular to faces; use shared trunks for fanout.
   Derive paths from one source-to-destination point list without independently
   rounding endpoints. Align marker tips exactly with destination ports.
4. Keep container backgrounds behind wires and node surfaces; put moving
   packets in the appropriate foreground layer. Size labels for the longest
   text across every state, not only the initial scene.

Geometry is complete when ports, arrowheads, labels, and routes remain aligned
without collisions in every supported state.

## Frame and operate the explanation

Scale the SVG through its `viewBox`. Use responsive page framing and allow
normal page scrolling when the explanation needs it; do not hide overflow to
force a zero-scroll page. Stack groups or controls at compact widths when
scaling alone makes labels unreadable.

Place controls beside the state they affect, expose current selections, and
provide keyboard access and visible focus. Give animated simulations pause,
step, and reset controls when relevant. Keep static topologies static unless
motion teaches an actual sequence, transition, or causal event.

Bind packet motion to the wire's exact ordered path. For native SVG
`animateMotion`, insert with `begin="indefinite"`, then call `beginElement()`
after attachment so late packets start at insertion time. Apply arrival effects
when packets arrive; remove completed packets instead of accumulating them.

Track playback intent separately from visibility. Suspend automatic work when
hidden or offscreen and resume without catching up background time. Manual
stepping pauses automatic advancement. Preserve the user's playback choice
across resets or mode changes unless the requested behavior says otherwise.

Check reduced motion before creating SVG or scripted animation, and respond to
preference changes. Preserve static arrows, labels, metrics, and discrete steps;
CSS alone does not disable native SVG motion.

## Verify and deliver

Inspect supported desktop and compact viewports, themes, and every control
state. Check reading order, text contrast, labels, exact ports, arrowhead
arrivals, stable semantic colors, and an explanation understandable without
color or motion. For charts, check axis labels, units, ranges, and the plotted
values against the source data or model.

For simulations, verify actual packet movement after delayed insertion, a full
sequence, pause/step/reset, mode changes, visibility suspension, and reduced
motion. Check offline loading when delivering a self-contained HTML artifact.
Report any checks unavailable in the environment rather than claiming them.
