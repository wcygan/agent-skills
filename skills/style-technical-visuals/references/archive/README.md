# Historical Technical Visual References

This archive preserves the skill's earlier galleries, article references,
pattern studies, source assets, and rendering postmortem. It records historical
approaches rather than defining the current workflow.

For new work, start with the [2D guide](../2d.md) or [3D guide](../3d.md) and
their standalone examples. Consult this index only for an explicit historical
request, provenance questions, or a useful pattern absent from those examples.
Load only the relevant resource; adapt borrowed patterns to the active guides.
