Requests stream from client queues into available pool slots, turning them green, querying MySQL, and releasing them back to idle (blue). After ~5 seconds, connection c3 enters a stuck/leaked state (uncommitted transaction or unclosed socket). Available capacity permanently drops, and incoming client requests start backing up in warning orange.
