Leftmost prefix rule

Secondary index on (user_id, created_at, region). Pick a WHERE clause; the left board scans the correct index, the right board a badly ordered one.

Index (user_id, created_at, region) — correct order

Index (region, created_at, user_id) — wrong order

The index is a sorted list; a query can walk it only where its predicates line up with the leftmost columns. An equality on the first column keeps the second sorted. A range stops that: (a, b, c) answers a = ? AND b = ? perfectly but degrades once b becomes a range. A query that skips column a entirely cannot use the index at all.
