Change Data Capture (CDC) decouples source OLTP databases from downstream consumers. Debezium tails the MySQL binlog with near-zero overhead compared to polling SELECT * FROM table. Every mutation emits a deterministic envelope (before, after, op, source_ts) into Kafka, allowing downstream search indexes, cache invalidators, and columnar analytical stores to consume changes independently without contending for primary transaction locks.
