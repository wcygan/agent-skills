Where does the excess work go?

Offer the same requests to three FIFO services. A buffer absorbs a short burst. Backpressure slows admission and keeps demand upstream. Load shedding gives excess requests an immediate rejection.

Blue: admitted queue / transfers. Yellow: retained upstream waiting / demand. Green: completed work. Red: discarded work. A queue slot is a waiting request; the worker has one separate in-flight slot. Each packet summarizes actual events in the latest step; counters show their resulting state.

Model: identical equal-cost requests, one FIFO worker per policy, exact service completion times, evenly spaced arrivals with a seeded initial phase. Queue wait is admission → service start. Upstream wait is offer → admission. Total latency is offer → completion. Latency averages include completed requests only; current oldest upstream age exposes requests still waiting. Throughput counts completions over the last 5 logical seconds, separate from admission.

The buffer-only lane has no upstream admission control; its finite buffer drops overflow. Backpressure admits against free downstream slots and retains desired requests at the producer. This models a pausable source or upstream application work, not a claim that every source can retain an unlimited backlog. Shedding admits only while fewer than 4 requests wait (half the capacity, rounded up), leaving spare buffer slots and rejecting excess early. Rejections consume no worker time; retries, deadlines, transport delay, and overload-induced slowdown are omitted.

Rates change the current run; changing arrival starts a new seeded arrival interval, and changing processing preserves work already done. Capacity and seed changes restart all lanes fairly. Playback advances by 0.25 logical seconds, suspends when hidden or offscreen, and sleeps when no work can change. Step and burst pause playback. Reduced motion starts paused and disables packets; Play or Step still advances discrete state. Each run ends at 120s or 6,000 offers; queues, request objects, completion samples, and chart history are bounded. Reset repeats the same seed and current settings.
