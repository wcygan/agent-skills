A ticket drop. A controlled front door.

When demand exceeds checkout capacity, a virtual waiting room holds users in a queue. Admission control lets a limited number proceed as capacity becomes available.

Inside the waiting room

A self-hosted reference design built from NGINX Open Source, custom admission services, Valkey, and PostgreSQL. Queueing and admission are application logic implemented using shared data structures and transactions.

MechanismWhat it does
NGINX Open Source + custom APIServe the waiting page and route check-ins. Use auth_request with the admission API for protected checkout routes; deny direct origin access. Poll with jitter to spread check-ins.
Valkey sorted setA short join script assigns a monotonic sequence with INCR and inserts the session with ZADD. Repeated joins reuse the session's existing position. Partition keys by sale; script keys must share a cluster hash slot.
Scheduler + atomic LuaEnforce both an admission rate budget and an active-session cap. Atomically claim the oldest waiting sessions and create expiring leases. Multiple schedulers use the same script so they cannot spend the same capacity twice.
Session cookie + leaseUse a signed opaque session ID in a Secure, HttpOnly cookie. Validate the server-side lease on protected requests; refreshing does not extend it indefinitely. The lease admits a user, not a seat reservation.
PostgreSQL transactionsLock a seat row with SELECT FOR UPDATE, check availability, and create a timed hold in one transaction. Unique idempotency keys deduplicate order retries. An expiry job releases abandoned holds; do not hold a database transaction open during payment.
Failure and recoveryConfigure Valkey persistence and replication; asynchronous failover can lose recent state. Pause admissions on uncertain state and reconcile leases before resuming. Atomic scripts alone do not provide durability or globally synchronized ordering across independent writers.

Building-block references: NGINX authorization subrequests · Valkey sorted sets · Atomic Lua scripts · PostgreSQL row locking.
