Reuse is efficient. Unbounded concurrency is expensive. Four interactive figures connect socket reuse to server pressure and pool exhaustion.

CONCURRENCY & THROUGHPUT

More connections eventually do less work

Explore a four-core workload: throughput rises, reaches a peak, then falls as contention grows.

Illustrative Universal Scalability Law: X(n) = 40n / [1 + 0.25(n−1) + 0.0013n(n−1)]. Latency = n / X(n), assuming zero think time. The 8–40 band is a starting heuristic, not a sizing guarantee.

Long queries hold every connection
