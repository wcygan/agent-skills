Failure detectors

Each follower has its own heartbeat timer

½ speed · simulation time

Scroll the diagram horizontally to inspect each follower’s deadline.

Failure detected

An arriving heartbeat resets that follower’s timer. A timeout creates suspicion, not proof of a crash; this demo pauses at the first timeout.

Receive, then restart

Deadline = timer start + a fresh, independently sampled timeout in [1.5, 3.0] seconds. Sending a heartbeat does not reset a follower. Delivery does.

Faults affect different things

Crash stops future broadcasts; hearts already in flight may still arrive. A cut removes traffic on one link. A drop discards only the next heartbeat to one reachable follower.

Suspicion is not proof

A live leader behind a broken link looks silent too. The ledger shows only each follower’s local evidence. Equal-time delivery is processed before expiry.
