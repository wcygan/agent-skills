Read the routing rule

Keys are bytes

Kafka Java-compatible Murmur2 hashes the UTF-8 key. Clear the sign bit, then take the remainder: (hash & 0x7fffffff) % N. Repeated keys choose the same log for a fixed N.

Offsets are local

Each partition starts at offset 0. Record IDs show producer order; offsets show order within one log. There is no single topic-wide offset.

Changing N changes routing

Changing the partition count here restarts the sample under the new rule. In Kafka, existing records stay in their original logs; later records with the same key may route elsewhere.
