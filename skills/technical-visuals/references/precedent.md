# Precedent and scope

This skill is a new design and implementation, authored for William Cygan's preference
for concise visual explanations. The historical `style-technical-visuals` skill at
`wcygan/agent-skills` revision `fe444ec0b007d73cff0445db7d223a34c4cc8cd5` informed topic
selection and preferences: restrained surfaces, orange focus, semantic shapes, and
readable technical labels. Its code and large gallery are not imported.

The fresh examples cover routing, bounded queues, cache paths, replication, ordered
records, and checkpoint recovery. They are simplified teaching models, not production
architectures or claims about a particular implementation. Each is paired with a
presentation failure and a concrete repair. Light mode is a newly specified peer of
dark mode, not a mechanical inversion. 3D is explicitly requested, never automatic.

Useful external format/accessibility references (consult when the task needs details):

- [GitHub Mermaid diagrams](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/creating-diagrams)
- [WCAG contrast minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)
- [WCAG non-text contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)

These references inform delivery and accessibility. They do not define this visual
style, and passing selected checks is not a claim of complete WCAG conformance.
