# Research

Investigate the question using primary sources: official documentation, source code, specifications, and first-party data. Follow material claims to the source that owns them; distinguish facts, inference, disagreement, and unresolved gaps.

Write findings to one Markdown file using the repository's existing notes convention, or choose a sensible location and report it. Cite sources near their claims and include the practical answer, relevant version or date, and remaining uncertainty.

Research directly, or delegate a bounded investigation when delegation is available, permitted, and lets useful independent work continue. Missing delegation does not block research. The research phase ends when the question is answered to the available evidence; continue any implementation already requested using those findings.
