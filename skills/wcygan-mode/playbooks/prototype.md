# Prototype

Build a small experiment to settle a design uncertainty.

1. State the question, alternatives, and observation that would decide between them.
   Prefer an experiment for observable uncertainty over asking the user to guess.
2. Set a small budget and isolate the sketch from production behavior. Keep necessary
   realism at the boundary that determines the answer.
3. Follow [experiment](../../wcygan-experiment/SKILL.md), recording actual observations.
4. Explain the decision supported by the prototype and the assumptions still untested.

Complete with a decision or an explicit inconclusive result. Label prototype shortcuts;
promoting the sketch to production requires normal implementation and verification.
