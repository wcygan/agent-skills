# Coordinate program

Coordinate a sustained project across multiple work units.

1. Define the completion predicate, tracks, dependencies, ownership, and budget. Use
   [coordinate-work](../references/methods/coordinate-work.md); keep one-session work lightweight.
   For outcome ownership with uncertain operational inputs or proof, use
   [prepare-agent-objective](../references/methods/prepare-agent-objective.md) first. Route
   recurring health or performance objectives through
   [maintain-outcome](../references/methods/maintain-outcome.md); an active execution trigger is needed
   for automatic future cycles.
2. For durable coordination, keep a [decision-log](../references/methods/decision-log.md) outside installed skills.
   Record instructions, units, verification evidence, unresolved gates, and
   current artifact identities.
3. Pilot one unit through execution, verification, integration, and the requested
   delivery stage before expanding. Fix weaknesses in the brief or proof method first.
4. Use [coordinate-work](../references/methods/coordinate-work.md) for the brief, isolated writes, evidence, and integration
   checks. Use `verify-behavior` for the final integrated acceptance criteria.
5. Use [progress-report](../references/methods/progress-report.md) at integration points. On restart, use [recover-context](../references/methods/recover-context.md)
   to reconcile live artifacts and owners with stored claims before dispatch.

Complete with every required unit accounted for, integrated evidence, and durable
handoff state. Inspect the evidence a log entry points to, because the entry
only records a claim.
