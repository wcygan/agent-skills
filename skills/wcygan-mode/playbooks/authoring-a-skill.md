# Authoring a skill

Create or revise an agent skill.

1. Establish the task the skill serves and the requests that should activate it.
   Inspect existing conventions and nearby skills before adding a new abstraction.
2. Write concise triggers, decision criteria, steps, and completion evidence. Keep
   common instructions in the entrypoint; link conditional details only where needed.
3. Reuse existing components rather than duplicating their instructions. Preserve
   source revision, license, and attribution for adapted material.
4. Validate format and references. Exercise executable helpers and representative
   behavior when the change affects consequential decisions.

Complete with a usable skill, evidence of validation, and known behavioral limits.
For project verification authoring, use [create-verification-skill](../../create-verification-skill/SKILL.md).
For formal verification of one property, use [create-formal-verification-skill](../../create-formal-verification-skill/SKILL.md).
