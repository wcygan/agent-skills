# Record

Read linked components only when their stated condition applies. Use available
tools and preserve the task's scope, prior authorization, and explicit checkpoints.


1. Choose the requested output. Use [decision-log](../decision-log/SKILL.md) for
   an ongoing audit trail, [recover-context](../recover-context/SKILL.md) for pickup,
   or [progress-report](../progress-report/SKILL.md) for a concise status update.
2. For a requested retrospective, use [improve-workflow](../improve-workflow/SKILL.md).
   Apply [prevent-recurrence](../prevent-recurrence/SKILL.md) when structural fixes
   to repeated mistakes are also in scope.
3. When asked to capture lasting personal preferences, use
   [personalize-workflow](../personalize-workflow/SKILL.md). Ordinary task notes do
   not by themselves justify permanent rules.
4. Check that evidence pointers resolve, uncertainty survives summarization, and
   unfinished work has enough context for its next owner. Use
   [write-clearly](../write-clearly/SKILL.md) when the prose needs refinement.

Done when the requested record is useful, accurate, and stored or presented in its
intended scope. Run only the relevant branch; an update does not require a retrospective.
